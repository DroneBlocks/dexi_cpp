# Examples

Teaching scripts. Not installed: run them from the source tree with the DEXI workspace sourced.

## Python

| Script | What it does |
|---|---|
| `python/example_pin_control.py` | Mirror TCA9555 input pin 4 onto output pin 0 |
| `python/example_toggle_pin.py` | Toggle TCA9555 pin 14 once a second |

Both need the TCA9555 controller running. Run with `python3 examples/python/<script>` from the package directory.
